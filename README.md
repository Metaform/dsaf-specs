dsaf-specs

## Specifications

- [Dataspace Core Messaging (DCM)](specs/dcm/core-messaging.md): CloudEvents-based foundation for event messaging between dataspace participants.
- [Supply Chain Certificate Exchange (SCE)](specs/sce/certificate-exchange.md): exchange of company certificates between supply chain participants, composed on DCM.
- [Structured Task Collaboration (STC)](specs/stc/task-collaboration.md): bilateral, long-running data collaboration between dataspace participants, composed on DCM.
